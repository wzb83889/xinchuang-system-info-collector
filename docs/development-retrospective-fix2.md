## 关键调试路径

### WebDAV 连通、认证与归档

- OPTIONS 收到 401 或 403 时继续到认证验证。临时目录创建、文件写入和清理通过后才打印登录成功。早期 401 排查覆盖应用权限、首次登录状态、认证方式和凭据尾字符。
- 重复提交时，MKCOL 的 405 只触发核验。PROPFIND 必须在同一服务及路径上返回成功的 `resourcetype=collection`。普通文件、禁止查询或缺失父目录会报告失败。
- 复现时先在新目录提交，再用同一部门与工位提交。依次记录预检、目录创建、目录核验、PUT 和清理的阶段与 HTTP 状态。

### 物理网卡与 MAC

- 简要、完整和批量入口使用同一枚举逻辑。优先取永久 MAC，必要时回退到当前 MAC。连接状态与 IP 反映网络现状。
- Wi-Fi 未关联、以太网禁用或未插线时，能读到 MAC 即可继续。必要网卡缺失、枚举失败或已发现的卡缺少 MAC 时，批量采集暂停，修正后仅重试网络模块。
- 复现覆盖 PCI、USB 扩展坞、禁用、Wi-Fi 断开、VMware、VPN、蓝牙 PAN 和 MAC 不可读。

### 姓名录入与兼容汇总

- 用代码页 936、65001 和 437，以及含扩展汉字的模拟姓名复现。逐段核对读入、JSON、CSV 与汇总值。已写入替换字符或 NUL 的旧姓名可能丢失原始信息。
- CSV 支持严格 UTF-8、带 BOM 的 UTF-16 和 GB18030 兼容解码，按标题归并并处理引号、逗号与跨行字段。
- 只有同名 JSON 的采集时间、计算机名匹配且姓名有效时才恢复原文。其余待人工核实。旧网卡无法完整拆分时保留原文。
