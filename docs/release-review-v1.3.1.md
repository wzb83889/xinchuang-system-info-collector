# v1.3.1 发布前代码审查

| 优先级 | 发现 | 处理与验证 |
| --- | --- | --- |
| 阻断 | 内部 fix2 源码及程序含部署参数 | 从公开主线移植，使用运行时配置。用模拟账号和回环服务测试，扫描交付源文件及二进制 |
| 高 | MKCOL 的 405 可能被误判为已有目录 | 核对同源、逐段相同路径与成功的目录属性。禁止自动跳转与 XML 外部实体。模拟已有目录、并发、普通文件、无权限、错路径与缺父目录 |
| 高 | `..` 或 Windows 保留设备名可使归档越级或失败 | 独立规范化目录段，保留登记原值。覆盖 `..`、`NUL.txt` 和编码路径分隔符 |
| 高 | 同设备同一秒重复上报可能撞名 | 批次标识增加毫秒和随机后缀。模拟同一人、同一工位连续上报，核对六个独立文件 |
| 高 | 表格软件可能把 CSV 中的文本解释为公式 | 保护表头和数据单元格中的公式前缀，普通带符号数字按原值输出，TXT 和 JSON 保留原文 |
| 高 | 缓存地址可能覆盖管理员的新配置，导致凭据发往旧服务 | 环境变量优先于地址缓存。手工换地址时重新输入凭据 |
| 中 | 归集失败仍可能返回成功退出码，输出可能包含目标地址 | 命令行失败返回非零。WebDAV 按连接和登录分阶段报告，成功列表仅显示文件名 |
| 中 | 驱动或系统权限可能影响物理网卡清单 | 分离适配器状态与 MAC 采集结论。识别不完整时交互重试或退出，覆盖 USB、虚拟设备、Wi-Fi 断开与以太网禁用 |

## 运行边界

- 固件禁用、驱动缺失或系统隐藏的设备可能无法枚举。程序根据可见清单及设备类型判断是否需要复核。
- 三种报告经独立 PUT 写入。上传途中断网可能留下部分报告，重试会使用新的批次。
- 已损坏且缺少可核对 JSON 的旧姓名需人工核实。
